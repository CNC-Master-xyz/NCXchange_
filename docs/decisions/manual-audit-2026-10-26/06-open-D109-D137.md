# Manual audit 2026-10-26, part 06: open D109 D137

Report of one audit agent, checked against the cnc-manuals connector (1283 manuals); kept as written. Page numbers are the connector's. The summary and the decisions it leads to are in `../manual-audit-2026-10-26.md`.

AUDIT REPORT: D109–D137 (my 22 entries), checked against the cnc-manuals connector

General note: the German Fanuc 30i-B Betriebshandbuch B-64484GE/02, which many entries cite, is not in the connector. Only three short chapter extracts of it are. I checked those citations against the English edition, Fanuc_30i-B_Bedienung-Drehen-Fraesen_B-64484EN (EN below), and give its pages. Pages differ from the German edition, but the content matches unless I say otherwise. Two more cited sources are listed in the connector but their text is not searchable or readable: the B+W MCX800-HVP Betriebsanleitung Band 1, and the body of the Siemens 840D Zyklen Programmierhandbuch 2008 and 2006 (only the index pages read).

D125 – NEWLY SETTLED BY THE MANUALS (Siemens half)
- Fanuc: work coordinate shift amount depends on diameter/radius programming: CONFIRMED, EN p.215. Work origin offset likewise: CONFIRMED, EN p.206–207.
- Siemens DIAMON diameter-data list (display, JOG, end positions, I/J/K with AC, MEAS / $AA_IW): CONFIRMED, NC-Programmierung 2019 p.169.
- The record calls "TRANS X under DIAMON is a radius" negative evidence. It is now stated positively: Grundfunktionen 2012 pp.901–902, "Fest Radius-bezogene Daten", lists for facing axes, always in radius: tool offsets, programmable and settable frames, external zero offset, DRF/Preset, working-area limitation, software limit switches, feed, and display data in the MCS.
- MD20360 TOOL_PARAMETER_DEF_MASK bit 3 = 1 switches zero offsets in frames to diameter (pp.902–903). Bit 5 does the same for the external zero offset.
- Effect: a Siemens reader must not halve TRANS X by default, but this depends on MD20360 bit 3, so it is a machine setting, not a fixed convention.

D126 – UNVERIFIABLE (Siemens half); Heidenhain half HOLDS

D129 – FACT WRONG

- WRONG generalisation: "wherever a machine has both a work spindle and a tool spindle, the bare spindle words are the work spindle's." On mill-based mill-turns it is the reverse:
  - Hermle MT machines (M-Funktionen 2015 p.1–5; Postprozessor-Heidenhain V2 2016 p.7): M3/M4/M5 = tool spindle, the work spindle has its own M303/M304/M305.
  - TNC 640 turning: the work spindle is switched with an OEM-specific M (M303, M304…), TNC640 Zyklen 2019 p.415.
  - TNC 640 Technisches Handbuch: MODETURN.H uses "M5 ;Werkzeugspindel HALT", p.2274 (2018 SP01) / p.2295 (2018-09) / p.2320 (2021).
- So the manuals split by machine family: lathe-based mill-turns default to the work spindle, mill-based ones to the tool spindle. They do not point at MAIN.

D137 – FACT WRONG
- Fanuc 1320/1321 (and 1322–1325): machine-coordinate stroke limits, diameter values on diameter axes: CONFIRMED. EN p.2069–2071; parameter manual p.74.
- "Counter-case: position switches 6930–6945 must be given as RADIUS values": WRONG. Parameter manual B-64490EN-05 p.397–398 and EN p.2195 say the opposite for 6930ff and 6950ff: diameter values on a diameter axis. Fanuc is then consistently diameter for machine-frame limit data, which strengthens the Fanuc half.
- Mori 3194 #3 machine coordinates shown as diameter in radius mode (M582): present on NTX1000 p.116–117; not re-read in detail.
- Siemens, "inferred diameter": WRONG for limits and home. Grundfunktionen 2012 pp.901–902 lists as always radius for facing axes: software limit switches, working-area limitation, frames and offsets, and all display data in the MCS. Programmed end positions under DIAMON, including G153 X under DIAMON as in DMG L710, are diameters.
- So on Siemens, [positions] used as program words under DIAMON = diameter, but machine-data limits and home are radius. "All four builder files can keep their numbers" must be checked for any Siemens builder file whose limits or home come from machine data.
- DMG L710.SPF: not in the connector (not a manual), UNVERIFIABLE.
- Doosan 2600 LSY II travel table: present at connector p.242 (record PDF 242), not re-read.

ENTRIES WHOSE PROPOSED OR GIVEN ANSWER WOULD CHANGE
- D129: drop "the manuals point at MAIN". Mill-based mill-turns (Hermle MT, TNC 640 turning) give bare M3/M5 to the tool spindle; lathe-based ones (Siemens lathe, Nakamura, Doosan) to the work spindle.
- D137: the Siemens half reverses for limits and home (always radius by Siemens definition); position-program words under DIAMON stay diameter. Delete the Fanuc position-switch "counter-case", which is wrong.
- D125: the Siemens half is now settled positively. TRANS and frame X is radius by default but switchable with MD20360 bit 3, so the reader needs that as a machine setting rather than a fixed rule.
- D126: the Siemens WCS quote the proposal uses against MACHINE cannot be verified, and the newer 840D sl manuals describe direct swivelling as machine swivel-axis positions. The "contradicts the recommendation" verdict should be softened or reopened.
- D134 (minor): correct "every bit defaults to keep". MD20112 defaults to 400H. The conclusion about the tool is unchanged.
- D123 (minor): withdraw "default SD42440 = 0"; it is unverified and possibly reversed. The conclusion is unchanged.
- Citation-only fixes, no change to the answer: D111/D116 (Fastems %MPF is pre-840D), D113 (EX1424 not PS0197; M70 at p.116–117), D116 (frames p.342; Fanuc p.58 in EN), D136 (Arbeitsvorbereitung p.189–190), and all Fanuc B-64484GE page numbers, which the connector can only check via the EN edition.
- D121 (maintainer answer) stands as given.
