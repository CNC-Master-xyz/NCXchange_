D253 (Heidenhain: a transform replaced by the next of its kind; cycle 247) — HOLDS. Point (c) remains UNVERIFIABLE, with one counter-hint.
- (a) A coordinate transformation acts from its definition until it is reset or redefined; the table lists cycles 7, 247, 8, 10, 11, 26, 19. CONFIRMED: iTNC530 Zyklen 670 388-12, p.278.
- (b) Datum shift before cycle 19 shifts the machine-fixed system, after it the tilted system. Reset in the reverse order of definition. CONFIRMED: iTNC p.301; TNC 640 Zyklen 892905-18 p.245, word for word.
- A new cycle 19 with other angles needs no reset first. CONFIRMED: iTNC p.302.
- Cycle 10 rotates about the active datum, is reset with ROT 0, and cancels radius compensation. CONFIRMED: iTNC p.289.
- Cycle 7: absolute values refer to the preset datum, incremental values to the last valid datum. Reset paths are as stated. Cycle 8 is reset with NO ENT. CONFIRMED: iTNC p.279 and p.287.
- Cycle 247 on the TNC 640 resets shift, mirror, rotation, scaling and axis-specific scaling, and names no plane. CONFIRMED: TNC 640 Zyklen p.247.
- Cycle 247 on the iTNC resets only an active datum shift. CONFIRMED: iTNC p.286. Side note: the iTNC says 247 is not effective in program test; the TNC 640 says it is.
- PLANE RELATIV is additive; PLANE must be cancelled with PLANE RESET, and 0 does not fully reset. CONFIRMED: iTNC530 Programmierung-Klartext 606420-01 (2010), p.459 and p.446.
- (c), the 7-10-7 case. New searches (DE/EN on transformation order, shift after rotation) still do not settle it.
  - New support for the order-sensitive chain: TNC640 Setup/Testing/Running EN 1261174-21, p.120-122. It says the result of stacked transformations depends on the programming sequence. It lists cycles 7, 8, 10, 11 and 26 as working-plane-system transforms, and advises programming and resetting only the recommended transforms in each system.
  - Counter-hint against the answer's leaning: iTNC p.279 says absolute cycle-7 values refer to the workpiece datum set by the preset. That hints the new shift is measured from the preset (the in-place reading) rather than along the rotated axes. It is not explicit, so the maintainer should still test it on the machine.

D283 (Fanuc units at power-on) — HOLDS, CITATIONS TO FIX.
- At power-on the G20/G21 state of the last power-off holds. G20/G21 goes in its own block at program start, before the coordinate system is set. WARNING: not to be switched during a program. CONFIRMED: 30i-B B-64484EN, p.226 (same page number as cited).
- The clear state leaves G20/G21 unchanged. CONFIRMED: EN p.62-63 (cited GE p.66).
- The power-on/clear/reset table repeats this. CONFIRMED: EN Appendix F, p.2409 (cited GE p.2372).
- The 0i-D says the same. CONFIRMED: 0i-D B-64304EN, p.121 (cited GE B-64304GE p.172, which is not in the connector).
- New facts, both strengthening the answer:
  - Note 4 on p.226: only G17-G19, G90 and G91 may share the G20/G21 block.
  - Conversion must be done at the machine origin or reference position unless parameter 14000#2 IRF or 11222#0 NIM is set; otherwise alarm PS5362 or PS1298 (p.226-227).
  - Parameter 11222#2 can disable G20/G21 altogether, leaving units to parameter 0#2 (Parameter manual B-64490EN p.586).

D278 (where Fanuc G70-G76 contour blocks stand) — HOLDS, CITATIONS TO FIX. One new fact matters for "written from an unknown state".
- The G71 format prints the contour blocks N(ns)..N(nf) directly under the two G71 blocks. F, S and T inside ns..nf are ignored. CONFIRMED: B-64484EN-1, p.53 (cited GE-1 p.56).
- After the roughing-as-finishing pass, the block after the Q block runs. CONFIRMED: EN-1 p.54 (cited p.57).
- G70 worked example: the ranges are named again, not rewritten. Up to three P/Q addresses are stored, and later cycles search memory. CONFIRMED: EN-1 p.76.
- Restrictions CONFIRMED on EN-1 p.90 (same page as cited):
  - no custom macro calls in a G70-G73 block;
  - the P block must hold G00/G01, else alarm PS0065;
  - only certain commands are allowed between P and Q;
  - a P/Q sequence number must not appear twice in the same program.
- Nakamura example (G71 P101 Q109, contour inline, later G70 P101 Q109; no subprogram call from ns..nf). CONFIRMED: Nakamura 4810004ECL-1, p.175.
- NEW, this changes the answer. On EN-1 p.55-57:
  - The ns block selects G71 type I or type II. Type I: only the X axis (second plane axis) in the ns block. Type II: both axes (W0 if Z does not move). Type II needs the "multiple repetitive canned cycle II" option.
  - If X does not move in the start block, alarm PS0325.
  - The proposed answer says writing from an unknown state "gives" the required G00/G01 anyway. But a compiler that writes the first contour block with both X and Z silently selects type II.

D249 — HOLDS, CITATIONS TO FIX, plus one caveat.
- Notes 1-5 (4-digit padding, P100100 / P50001; no L with the combined form; repeat count must be given for 5+ digit numbers). CONFIRMED: B-64484EN p.330 (cited GE p.335).
- "M98 P51002" = program 1002 five times. CONFIRMED: EN p.331 (cited p.336).
- The program number is O plus 4 digits, 8 with the "8-digit number function". CONFIRMED: EN p.323 (cited p.327). It is also selected by parameter 11304#3 ON8 (EN p.313-314).
- The table of three call formats was not visible as text (likely a figure).
- CAVEAT, new: in the optional Series 15 program format (parameter 0001#1 FCV), a P of more than four digits takes its last four digits as the program number, and a missing L means once. So there M98 P51002 is program 1002 called once. In the Series 30i format, L is usable only with the custom macro option. Source: B-64484EN-1 p.245-246; EN-2 p.298. So main's rule holds only for the 30i program format, which is worth a sentence.

ENTRIES WHOSE PROPOSED ANSWER WOULD CHANGE
- D279: drop "G74 has no Q". With rigid/peck tapping, G74 takes Q as peck depth (EN-2 p.110), so PECK on G74 maps to Q. Add the shared-modal-Q caution (EN-2 p.64-65).
- D278: add the G71/G72 type rule (EN-1 p.55-57). The ns block's axis words choose type I or II, type II needs an option, and alarm PS0325 fires if X does not move. Writing the first contour block "from an unknown state" with both axes silently selects type II.
- D249: add the Series 15 program-format exception (EN-1 p.245-246). There P51002 without L is program 1002 called once, so main's rule holds only for the 30i program format.
- D253: no change to (a), (b) or (d). For (c), soften "I do not think the manual points to the in-place reading": iTNC p.279 (absolute cycle-7 values refer to the preset) mildly points that way. The question still needs the machine.
- D283: no change of direction. Optionally add the reference-position condition and parameter 11222#2 (EN p.226-227; Parameter manual p.586).
- All other entries hold; only their citations need the connector pages listed above. The manuals now seen do not newly settle any entry the record called unsettled (the 7-10-7 order, the iTNC 530 ROT default, the D264/D266/D272/D274/D276/D277/D280/D282 design questions).
